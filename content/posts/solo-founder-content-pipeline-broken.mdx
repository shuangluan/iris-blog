上周我 build 完自己的博客，开始想解决下一个问题：怎么管我要发的东西、怎么让它真的出去。我打开了几个 headless CMS 的官网，准备开始 evaluate 哪个接进去成本最低。看到第三个的时候我停下来了。

「等等 —— 我以前的工作，不就是给别人 build 这种东西吗？」

我在 ByteDance 和 TikTok 做过五年的产品经理，全都在运营后台 / 平台效率工具这一块 —— TikTok 的 User 模块、内部运营流程工具、跨端的 admin dashboard、给几百人运营团队用的各种内部平台。大厂里这类产品最难受的地方是 **很难验证价值**：你的用户是自家同事，他们不用付钱，只是"公司规定要用这个"，所以你永远不知道你做的东西是真的好用还是他们只是没得选。

现在我离开大厂做 solo founder，遇到的每一个问题其实都在告诉我 —— **那些大厂里做过的东西，外面世界严重缺**。

## 过去两周给我摩擦的三个地方

自己 build 项目的时候，我卡住过三次：

1. **工具账号 sprawl** —— 为了 build 一个东西我注册了一堆工具的账号。有些用了两次就没再打开，我甚至不记得我全都注册了什么。没有一个地方能一处 grep。
2. **idea → 文章** —— 我知道自己脑子里有东西想说。但坐在 blank page 前的时候不知道从何写起。这就是为什么我最近发的 blog 都是让 AI 采访我、我口述、再转成文章。
3. **文章 → 分发** —— 写完了之后，一堆社媒账号我一个都没更新。每个平台的 tone 不同，我没精力去想每个平台该怎么发。文章就死在了自己博客上。

第一个是背景噪音。**第二个和第三个才是同一件事的两半 —— 一条被截断的内容流水线。**

## 一条被截断的流水线

一个 solo founder / 独立创作者的完整内容流程应该是：

```
脑内碎片 → 结构化 idea → 长文主稿 → 多平台适配 → 排期分发 → 反馈回流
```

现在市面上覆盖后半段的工具很多：Buffer / Hootsuite / Typefully / Beehiiv / Publer 都在做「排期 + 分发 + tracking」。但**前半段几乎没人做**：从"我知道我有话说"到"结构化的稿子"，中间需要的是**主动性** —— 一个会追问、会判断哪个点值得放大、会帮我把散的思绪结构起来的东西。

不是 Notion AI 那种被动等你输入的 assistant。是一个 agent。会问你「你上周有没有一件小事在心里翻过好几次？」然后顺着你的回答挖，最后告诉你「这里有三条可以写成一篇的线索」。

**这个能力两年前不存在。** 2024 年之前的 LLM 还不能持续、有记忆、有 judgment 地担任一个「编辑」角色。2026 年可以了。这是 "why now"。

## 大厂内部平台的假设错了

我在大厂里做过的所有平台，默认假设都是 **「20 个运营 + 3 个 PM + 5 个工程师」在用**。所以 UX 是给"团队协作"设计的，permission 是给"多角色"设计的，dashboard 是给"给老板汇报"设计的。

2026 年 solo founder 的假设是 **「1 个人 + 一堆 AI agents」**。permission 不重要（就我一个人），dashboard 不用给谁看（我自己看），协作 flow 不需要（我 + AI 就够了）。

**同一类工具，两种完全不同的假设，就应该是两种完全不同的产品。**

Buffer 是给 5 人 marketing 团队设计的分发工具，不适合一个人跑 5 个平台，因为它不 handle 前面的"怎么产出"和"怎么改 tone"。Notion AI 是给"我知道自己要写什么"的人用的，它不 handle "我知道我想说但不知道怎么开始"。中间那一整段 —— 从脑内到稿子、从稿子到平台版本 —— 是空白。

## 我要做什么

我在给自己 build 这条流水线。因为我就是最痛的用户，每次自己 hit 到痛点就是一次天然的用户访谈。

v0 会长这样：

- **AI 采访** —— 你口述，它追问，帮你把碎片抓成结构化的 idea
- **主稿生成** —— 长文主稿（blog / newsletter）
- **多平台改写** —— 一键出小红书 / LinkedIn / X thread / 公众号 / 朋友圈的对应版本，每个都懂那个平台的 tone、字数、视觉需求
- **审 + 发** —— 一页 review，每个平台单独 approve 或 re-edit，一次发完，结果回流到同一处

我会先自己用。用得顺就给几个朋友试。试得顺就 open beta。

**如果你也是那种"写完就 stuck 在自己博客上"的人 —— 或者反过来，"想写但不知道从何写起"的人 —— 跟我说一声，我加你 early access 名单。**
